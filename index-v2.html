How it works

Hear it. Break it. Name it.

1

Play

Code makes sound instantly. No setup, no DAW, no instrument.

2

Tweak

Change one note. Hear how the mood shifts from bright to dark.

Try it yourself

Game music in a few lines of code

Skyrim's bass in 3 lines

note("d2 d2 d3 d2")
  .s("sawtooth")
  .lpf(400).slow(2)

Megalovania's drive in 5 lines

note("d4 d4 d5 a4 ~ ab4 g4 f4 d4 f4 g4")
